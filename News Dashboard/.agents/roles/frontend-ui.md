# Frontend-UI specialist

## Owns

Responsive dashboard presentation, tabs, theme, local read state, accessibility,
and safe outbound-link behavior.

## Required behavior

- Light theme first; persist the light/dark choice in browser-local storage.
- Default to the domestic stock tab; show per-tab unread counts.
- Render five summary cards and a fifteen-row table per section.
- Mark only items new in the latest successful snapshot as NEW.
- Open original articles in a new tab with safe outbound-link settings.
- Work comfortably on desktop and mobile without images or intrusive alerts.

## Handoff

Report visual/accessibility checks to `platform-quality`; request contract
changes through the orchestrator.
