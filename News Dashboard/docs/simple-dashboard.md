# 뉴스 모아보기 — 실행 안내

현재 버전은 뉴스 제목·언론사·발행 시각·원문 링크를 모아 보는 개인용
대시보드입니다. 본문을 수집하거나 새 기사를 작성하지 않습니다.

## 실행

Node.js 22.18 이상에서 저장소 루트를 기준으로 실행합니다.

```powershell
npm ci
npm run refresh
npm run dev
```

브라우저에서 `http://127.0.0.1:4173/`을 엽니다. 터미널을 닫으면 서버와
자동 수집이 종료됩니다. 화면의 새로고침은 RSS를 수집하고 목록을 다시
읽습니다. 중복 요청은 합치며, 수집은 최소 1분 간격으로 제한됩니다.

서버가 켜져 있을 때 한국시간 06:07 / 09:07 / 12:07 / 15:07 / 18:07 /
21:07에 자동 수집합니다. 꺼져 있던 시간의 작업은 소급 실행하지 않습니다.
새로 수집한 목록은 화면 새로고침 시 보입니다. 언제든 `npm run refresh`로
수동 수집할 수도 있습니다. 수동 CLI 수집은 서버의 자동 수집과 동시에
실행하지 마세요.

## 현재 기능

- 정치·경제·증권·해외증시·사회·국제·엔터·스포츠, 기본 탭은 증권.
- 분야별 최대 20건을 최신순으로 표시. 상위 5건은 카드, 나머지는 표.
- 최근 24시간 분량이 적으면 저장된 최대 7일 이내 기사도 함께 표시.
- 제목을 누르면 원문을 새 탭에서 열고, 이 브라우저에 읽음 상태를 저장.
- 라이트/다크 모드 선택 저장. 브라우저 저장소를 사용할 수 없어도 열람 가능.
- 마지막 성공 수집 시각 표시. 실패하면 기존 JSON과 NEW를 유지.

## 단순한 구조

```text
기존 SBS RSS 수집기 → 작은 JSON 파일 → HTML / CSS / JavaScript
```

추가 라이브러리, 프런트엔드 프레임워크, 데이터베이스는 없습니다.
`apps/web`은 화면, `packages/pipeline/src/dashboard/snapshot.ts`는 목록
선택과 안전한 저장, `scripts`는 수집·서버·정적 빌드를 담당합니다.
`apps/web/data`의 실수집 데이터와 `dist`는 Git에서 제외합니다.

새 계약은 `news-dashboard.links/1`이며 `refreshedAt`, 여덟 `sections`를
가집니다. 각 기사는 `stableId`, `title`, `publisherName`, `articleUrl`,
`publishedAt`, `isNew`만 저장합니다. 빈 분야도 유효합니다. 기존의 큰
`snapshot-v1.md` 계약은 향후 제안으로 남겨 두며 현재 화면에는 적용하지 않습니다.

중복 제거는 원문 URL과 공백을 정리한 동일 제목을 기준으로 합니다.
다른 제목으로 보도된 같은 사건을 자동으로 묶는 기능은 아직 없습니다.
NEW는 직전 성공 목록에 없던 ID/제목에 붙으며 첫 수집에서는 모두 NEW입니다.
같은 URL의 제목이 바뀌면 최신 수집 값을 사용합니다.

## 출처와 남은 범위

[SBS 공식 RSS 안내](https://news.sbs.co.kr/news/rss.do)를 2026-09-08 다시
확인했습니다. 개인의 비상업적 사용을 명시하며, 기존 여섯 분야 피드를
그대로 사용합니다. 기사 본문 요청은 하지 않습니다.

현재 출처는 SBS 한 곳입니다. 증권·해외증시는 적거나 없을 수 있으며
실제 개수를 그대로 표시합니다. AI 요약, 종가 패널, 추가 언론사,
항상 켜진 수집과 외부 배포는 이후 작업입니다. 외부 배포 시 기존의
소유자 전용 접근 설정 결정을 적용해야 합니다.

## 확인

```powershell
npm test
npm run build
npm run check:leaks
```

빌드는 실수집 JSON을 검증한 뒤 화면과 데이터만 `dist/`에 복사합니다.
정적 배포본 자체에는 수집 서버가 포함되지 않습니다. `npm run dev`는
이 컴퓨터의 127.0.0.1에만 바인딩하고 승인한 정적 파일만 제공합니다.

2026-09-08 실수집: 표시 124건(정치 20, 경제 20, 증권 4, 해외증시 0,
사회 20, 국제 20, 엔터 20, 스포츠 20), 피드 오류 없음.

자동 테스트 11개, 정적 빌드, 누출 검사, 화면/자료 HTTP 응답과 원문
수집 새로고침을 확인했습니다. 브라우저 미리보기를 열었으며, 실제
클릭·모바일 화면에 대한 시각 검수는 아직 수행하지 않았습니다.
